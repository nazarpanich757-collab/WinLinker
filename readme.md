# WinLinker На русском

## Особенности

WinLinker предоставляет удобный графический интерфейс в Microsoft Windows, позволяя пользователям создавать жёсткие/символические/соединительные ссылки через контекстное меню Проводника или Рабочего стола.

## Использование

1. Нажмите правой кнопкой мыши на
   * выбранный файл
   * выбранную папку
   * фон Проводника или Рабочего стола
2. Выберите «Показать дополнительные параметры» (только в Windows 11)
3. Выберите «Create Link» (Создать ссылку)
4. Выберите «Create Here»[^1] или «Link Here»[^2] (только если вы нажали правой кнопкой мыши на фон в шаге 1)
5. Отредактируйте путь к назначению ссылки (под меткой «Destination»)
6. Отредактируйте свойства входа ссылки (под меткой «Entrance»)
   - Отредактируйте имя ссылки (под меткой «Name»)
   - Выберите тип ссылки
     - жёсткая[^3]
     - символическая[^4]
     - соединительная[^5]
   - Отредактируйте путь к папке, где размещается ссылка (под меткой «Folder»)
7. Нажмите кнопку «Create» (Создать)

## Сборка

### Исполняемый файл

Требуется интерпретатор Python. Чтобы скачать и установить интерпретатор Python, обратитесь к разделу [Downloading Python](https://wiki.python.org/moin/BeginnersGuide/Download#Windows).

Выполните следующую команду для установки соответствующих пакетов:

    pip install -r requirements.txt

Выполните следующую команду для создания исполняемого файла:

    pyinstaller --workpath build/pyinstaller_workpath --distpath build --clean -y build/winlinker.spec

Исполняемый файл и другие соответствующие файлы будут помещены в каталог `build/WinLinker`.

### Установщик

Выполните следующую команду для установки WiX Toolset:

    winget install --id WiXToolset.WiXCLI -i

Выполните следующую команду для получения расширения пользовательского интерфейса для WiX Toolset:

    wix extension add WixToolset.UI.wixext

Выполните следующие команды для создания общесистемного установщика и установщика для отдельного пользователя:

    wix build -arch x64 -bindpath "ToBeHarvested=../WinLinker" -d "LicensePath=build/installer/license.rtf" -ext WixToolset.UI.wixext build/installer/winlinker_machine.wxs -out build/installer/WinLinkerSetup_<version>.msi
    wix build -arch x64 -bindpath "ToBeHarvested=../WinLinker" -d "LicensePath=build/installer/license.rtf" -ext WixToolset.UI.wixext build/installer/winlinker_user.wxs -out build/installer/WinLinkerUserSetup_<version>.msi

> Замените `<version>` на фактическую версию, например `v1.0.0`

Установщик будет помещён в каталог `build/installer`.
